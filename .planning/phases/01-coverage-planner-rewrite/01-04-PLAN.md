## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser ↔ rosbridge | User-initiated PlanCoverage.action goal crosses from browser JS to rosbridge_websocket; goal fields are user-controlled |
| Browser ↔ Mapbox | GeoJSON data is rendered by Mapbox GL JS; injection requires malformed FeatureCollection input |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | Tampering | PlanCoverage goal from browser | mitigate | Server-side validation in coverage_planner_node (Plan 05). Browser-side, the hook sends only typed JS objects via roslib.ActionClient; no string concatenation into ROS2 messages. |
| T-04-02 | Information disclosure | error.human_readable rendered in notification.error description | accept | Operator-facing string only; coverage_planner_node constructs it from polygon indices and validation labels, never from user input. Low risk. |
| T-04-03 | XSS | Mapbox popup rendering segment_type / blade / speed | mitigate | React JSX auto-escapes; this plan FORBIDS unsafe HTML-injection props (acceptance criteria includes a negative grep for innerHTML and dangerouslySetInnerHTML in all touched files). The hover popup renders only enum strings (segment_type names from a fixed lookup table) and numbers. |
| T-04-04 | DoS | User spamming Preview Plan button | mitigate | AsyncButton's loading prop disables the button during in-flight goal. The hook's planning_active state ignores re-entrant requestPlan calls until the previous one resolves. The action server itself rejects concurrent goals (Plan 05). |
| T-04-05 | Trust integrity | Local-storage / cached narrow_area_strategy value out of valid 0-2 range | mitigate | Hook normalizes to value ?? 0 (Skip is the safe default). Backend (map_server_node, Plan 06) range-checks 0-2 on save and on serve. |

Severity: low. No high-severity threat. New attack surface is bounded by the rosbridge websocket policy (already in place for the rest of the GUI).
</threat_model>
