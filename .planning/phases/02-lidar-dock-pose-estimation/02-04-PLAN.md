<objective>
Implement SPEC R-2 + R-3: a new `dock_scan_match` rclcpp node that runs `kinematic_icp::pipeline::KinematicICP` against the one-time `dock_scan.pcd` snapshot at 10 Hz (D-07), publishes `/dock_match/pose` + `/dock_match/confidence`, and self-classifies trustworthiness per the SPEC R-3 thresholds (D-08 defaults).

Per RESEARCH §Pattern 1 + §Code Examples Example 1, the node:
1. Loads `dock_calibration.yaml` (dock anchor in map frame) and `dock_scan.pcd` at startup; if either is missing, enters degraded mode (publishes `confidence{trusted=false}` continuously per Open Q3).
2. Wraps the kinematic_icp solver behind `IDockMatcher` (D-16 — Plan 02-02 froze the contract; this plan ships the production impl `KinematicIcpDockMatcher`).
3. Subscribes to `/scan_kicp` with SensorDataQoS, projects each LaserScan to `vector<Eigen::Vector3d>` via `laser_geometry::LaserProjection`, crops to `±crop_radius_m` around the dock anchor, calls `RegisterFrame`, computes confidence post-hoc via Plan 02-02's `compute_confidence`, publishes both topics on a 10 Hz wall-timer.
4. Watches the dock_scan.pcd file mtime; on change, atomically reloads the matcher (Open Q4 thread-safety).
5. Gates RegisterFrame on TF distance to dock (Pitfall 5 mitigation): when robot is > 5 m from dock_anchor, skip ICP entirely and publish trusted=false.
6. Is wired into `navigation.launch.py` so the node starts with the rest of the navigation stack.

Architecture Invariant #1 (single localizer): dock_scan_match NEVER publishes TF. The pose lands on `/dock_match/pose` only. Plan 02-05's `dock_yaw_to_set_pose` cascade is the SOLE path that turns the LiDAR match into an EKF seed — and it does so via `/set_pose`, not TF.

Purpose: This is the central scan-match node. Every downstream consumer (FineDock, dock_yaw_to_set_pose, RecordDockApproachPose, GUI) sits behind these two topics.
Output: `/dock_match/pose` and `/dock_match/confidence` flowing on a real Pi5 LiDAR setup; gtest covers degraded mode + corruption-rejection + mtime-reload + TF distance gate.
</objective>
