Implement SPEC R-4: extend the existing `dock_yaw_to_set_pose.py` priority cascade so that `/dock_match/pose` (when `confidence.trusted == true`) wins over the existing dock_calibration.yaml file source AND `/gnss/heading`. The cascade becomes:

1. `/dock_match/pose` (LiDAR match, gated on `confidence.trusted`) — NEW top priority
2. `dock_calibration.yaml` (file) — existing
3. `/gnss/heading` (live, GPS course-over-ground) — existing fallback

Improves dock-yaw accuracy for the next undock and reduces compounding drift across charge cycles.
Output: dock_yaw_to_set_pose.py with the 3-source cascade; pytest covers the truth table; runtime log confirms which source was used per cycle (operator-visible in `ros2 topic echo /rosout`).

Cascade rule (cleanly inserted ABOVE the existing file/heading branch):
```python
def _resolve_yaw_source(self) -> tuple[str, float, float]:
    """Return (source_label, yaw_quat_or_rad, yaw_variance). Caller wraps into /set_pose."""
    now = self.get_clock().now()
    # ---- Priority 1: LiDAR match (R-4) ----
    if self._latest_dock_match_trusted and self._latest_dock_match_pose is not None:
        if self._latest_dock_match_pose_at is not None:
            age_s = (now - self._latest_dock_match_pose_at).nanoseconds / 1e9
            if age_s <= 1.0:  # don't trust matches older than 1 s (R-3 1-s abort horizon)
                yaw = quaternion_to_yaw(self._latest_dock_match_pose.pose.pose.orientation)
                # Use the published covariance (clamped to a sensible floor)
                yaw_var = max(self._latest_dock_match_pose.pose.covariance[35], 1e-4)
                return ("lidar", yaw, yaw_var)
    # ---- Priority 2: dock_calibration.yaml (existing) ----
    if self._file_yaw_rad is not None:
        return ("file", self._file_yaw_rad, self._file_yaw_var)
    # ---- Priority 3: /gnss/heading (existing) ----
    if self._latest_heading is not None:
        yaw = quaternion_to_yaw(self._latest_heading.orientation)
        return ("/gnss/heading", yaw, self._yaw_var)
    return ("none", 0.0, math.inf)  # nothing to seed; caller skips publish
```
